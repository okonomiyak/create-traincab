# Train Cab HUD

[Create](https://github.com/Creators-of-Create/Create) の列車を、本物の鉄道のように運転・乗務するためのアドオン Mod です。

A Create add-on for realistic train driving: stepped master controller, cab HUD, station stop assist, conductor duty with door control, pressure gauge, horn and music horn.

## 対応バージョン

| ブランチ | Minecraft | ローダー | Create |
|---|---|---|---|
| [`1.21.1`](https://github.com/okonomiyak/create-traincab/tree/1.21.1) | 1.21.1 | NeoForge | 6.0.11 以降 |
| [`1.20.1`](https://github.com/okonomiyak/create-traincab/tree/1.20.1) | 1.20.1 | Forge | 6.0.8 以降 |

サーバーとクライアントの両方に、同じバージョンの jar を入れてください。

## 主な機能

- **段階式マスコン**:P5〜N〜B7・非常の段階で操作します。レバーサ(前/中/後)付きです。
- **運転台 HUD**:画面下に速度計、ノッチ、状態、次駅までの距離をコンパクトに表示します。
- **駅停止支援**:停止位置までの残り距離を表示します。手動で止めても駅に到着した扱いになり、停止位置の精度を評価します(優/良/可)。
- **車掌乗務**:列車に組み込んだ車掌ブロックから乗務します。できること:
  - Create のスライドドアの戸開・戸閉
  - 戸閉チャイム、戸挟み検知
  - 車掌非常ブレーキ
  - 発車ベル / 発車メロディ(ホームに置くブロック。鳴り終わるまで戸閉できない)
  - 合図ベル、車内放送
- **高度運転台**:運転台としての機能に加えて、ブレーキシリンダー(BC)圧力計が付きます。
- **警笛とミュージックホーン**
- **緩解音**:ブレーキを緩めると「プシュー」と鳴ります。

## 操作

| キー | 運転士 | 車掌 |
|---|---|---|
| W / S | ノッチを力行側 / ブレーキ側へ(長押しで連続) | — |
| X | 非常ブレーキ | 車掌非常の動作 / 解除 |
| R / V | レバーサを前 / 後へ(停車中のみ) | — |
| K | — | 戸開 / 戸閉 |
| J | — | 発車ベル / 発車メロディ |
| B | 合図ベル | 合図ベル |
| N | 車内放送(ワンマン時) | 車内放送 |
| H | 警笛 | — |
| M | ミュージックホーン | — |

キーはすべて、操作設定の「Train Cab HUD」から変更できます。

HUD の位置・大きさ・単位やマスコンの加減速などは、「Mod」一覧 → Train Cab HUD → 「設定」から、Create と同じ設定画面で変更できます。

## ブロック・アイテム

| 名前 | レシピ |
|---|---|
| 高度運転台 | Create の運転台 + 時計 + 鉄インゴット(形は自由) |
| 発車ベル | 音ブロック + 鉄インゴット + レッドストーン(形は自由) |
| 車掌ブロック | 鉄インゴット・石のボタン・レッドストーン |
| 車掌帽 | 青の羊毛・金塊・黒の羊毛 |

## ビルド

```sh
./gradlew build
```

成果物は `build/libs/` に出力されます。必要な JDK は、1.21.1 版が Java 21、1.20.1 版が Java 17 です。Gradle が自動で用意します。

開発中に動作を確認するには `./gradlew runClient` を実行します。
